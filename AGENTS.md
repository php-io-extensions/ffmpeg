# Agent guidance — php-io-extensions/ffmpeg

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing the API, the C, or packaging. Open only the concepts the change touches.
2. **Bindings are 1:1 at FFmpeg's C API.** Function and constant names are the C names. No defaults, no composites. The floor is FFmpeg 7.1 (Debian trixie); Homebrew builds against a newer FFmpeg. Bind a function or constant only when FFmpeg 7.1 and the newest FFmpeg in `scripts/support.php` (`SUPPORT_NEWEST`) both declare it: FFmpeg removes deprecated functions between majors. `SwsContext` has no typedef in 7.1: write `struct SwsContext`.
3. **Translations, the only ones.** A C array of plane addresses or strides is one PHP list of ints; the binding pads it with NULL (0) to the entries FFmpeg reads (4 for `sws_scale`, 64 for `swr_convert`, one per stream for `avformat_find_stream_info`). An `X **` the function fills or frees is a by-reference parameter: the binding releases the handle it held when FFmpeg freed or replaced the object, and stores the new handle or null. An out-buffer (`char *errbuf` plus its size) is a by-reference string. A `void *` is an `int` address, trusted; `0` is NULL. Failure is FFmpeg's negative return, read with `av_strerror()`.
4. **Handles.** `final`, private `__construct`, not cloneable, not serializable, `pointer(): int`, `static fromPointer(int $pointer): ?static`. One PHP object per native pointer (`ffmpeg_box`). `fromPointer(0)` is `null`. Any other address is trusted. Dropping the PHP object does not free the native object. An object another one owns (`AVStream`, `AVCodecParameters`) is kept by its owner (`ffmpeg_box_kept`) and released with it.
5. **Fields.** FFmpeg's data is mostly public struct fields. A getter is named as the field, listed under `glue` in `bindings.json`, and added to the table in `src/fields.c`. Every getter's method entry is `ffmpeg_field`: the library's C file maps `zim_<Class>_<field>` to it before it includes the arginfo. That function holds the one refusal for a released handle.
6. **Value structs.** `AVRational` and `AVChannelLayout` are `final` classes with public `int` properties named as the C fields (`AVChannelLayout::$u` is the union: the mask, or the custom map's address). Functions that write the struct write the properties back.
6a. **Refusals.** Only memory unsafety of the wrapper, uncatchable process death or VM corruption, proven by a probe. Kept refusals carry `/* binding:<id> */`, read `if (!FFMPEG_PROBE_OFF("<id>") && (<check>))`, have a `sites` entry in `bindings.json` (Angel edits it) and a probe in `tests/Probes` (`ffmpegProbe()` in `tests/Pest.php`). The probe file is committed before the `sites` entry. Probe builds use `FFMPEG_CONFIGURE=--enable-ffmpeg-probes`. Never ship a probe build.
7. **The stub is the declaration.** One stub per library in `stubs/`, registered from the C file of the same name. Edit `stubs/*.stub.php`, regenerate with `php84 /opt/homebrew/opt/php@8.4/lib/php/build/gen_stub.php stubs`, and commit both. Never hand-edit `*_arginfo.h`. A constant's docblock is multi-line (`@var int`, `@cvalue`).
8. **Build.** `./install-macos.sh` into Homebrew `php@8.4` and `php@8.4-zts`; `./install-debian-trixie.sh` on Debian and the Pi. Tests need a temporary `composer install`; remove `vendor/` and `composer.lock` after. Gate a commit on the suite's exit code.
9. **The test fixture** is base64 text (`tests/Fixtures/*.b64`): the guard blocks binary writes into the repo. `videoFixture()` decodes it and checks its SHA-256.
10. **Durable facts go in `.okf`.** Update the matching concept and append `.okf/log.md`. Run `php84 scripts/support.php` after a stub change.
11. **Version** is `PHP_FFMPEG_VERSION` in `php_ffmpeg.h`: 0.11.0. `os-families`: linux, darwin.
